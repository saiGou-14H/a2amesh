# A2AMesh 历史设计归档

本目录保存已发布但已被替代的设计文档和版本化架构渲染资产，仅用于审计、差异比较和历史追溯。

- 当前权威设计：[`docs/specs`](../specs/README.md)
- `v1.0`：首版主专项及 Artifact、受信配置、人工对账三个闭环专项的首版文档
- `v1.1`：对称路由、双 Binding、MCP 桥和追踪合同
- `v1.2`：Canonical Principal、MCP 幂等、OAuth AS/JWKS 和 tenant 空值合同
- `v1.3`：累积交付剖面、Redis outbox、side-effect ledger、capability/admission、RTO/RPO 和 Card publisher 合同
- `v1.4`：Artifact/Object Store、受信配置和人工对账闭环，以及 NFR-003 澄清前的主专项基线
- `assets`：V1.1/V1.2 的 PNG、SVG 和自包含 HTML 架构渲染

归档文件不可作为当前实现依据，也不应被活动 README、代码注释或新测试 fixture 引用。需要修订当前设计时，从最新活动文档递增版本，不修改归档内容。
