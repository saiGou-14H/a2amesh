标准 A2A 边界

Agent Card、A2A-Version 1.0、JSON-RPC/HTTPS、SSE 和官方 SDK 类型均由 Gateway 提供。

NATS 数据面

所有 peer 主动出网连接；Request/Reply、私有 Inbox 和 JetStream 事件重放解决跨 NAT 调用。

Redis 状态平面

Redis 仅由 State Service 私网访问，负责 Card/Task 索引、幂等、租约、分页、Push 配置与限流。

Target architecture — compatibility must be proven by official A2A SDK black-box tests.
